# Kindow — сайты, боты и Mini Apps

Рекламный одностраничный сайт digital-студии Kindow. Проект выполнен на чистых HTML, CSS и JavaScript: без сборщика, внешних библиотек и обязательных зависимостей.

## Что внутри

- адаптивный лендинг с авторской тёмной визуальной системой;
- анимации появления, бегущая строка, интерактивная hero-композиция;
- услуги: сайты, Telegram-боты и Telegram Mini Apps;
- блоки с форматами запуска, процессом и ответами на вопросы;
- форма, которая собирает сообщение, копирует его и открывает чат `@kindow`;
- Open Graph-метаданные, favicon и базовый `robots.txt`;
- поддержка `prefers-reduced-motion` и управление мобильным меню с клавиатуры.

## Локальный запуск

Можно открыть `index.html` напрямую или запустить любой статический сервер, например:

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## Публикация

Проект подходит для GitHub Pages, Netlify, Vercel и любого статического хостинга. Для GitHub Pages достаточно выбрать ветку с сайтом и папку `/ (root)` в настройках Pages.
