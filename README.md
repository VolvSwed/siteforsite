# VYRAZ.BY — сайты, боты и Mini Apps

Автономный сайт digital-студии для белорусской аудитории. Публичная часть, формы, SQLite-база и защищённая админка работают в одном обычном Node.js-приложении — без Wrangler, Cloudflare и сборщика.

## Возможности

- выразительный адаптивный интерфейс с микроанимациями и интерактивной сценой;
- защита от горизонтальной прокрутки и безопасные сетки для мобильных экранов;
- пять слоганов, которые меняются при новом посещении;
- заявки через сайт с обязательным email;
- отзывы с именем, email и премодерацией;
- управление заявками, работами, отзывами и текстами через `/admin`;
- SQLite с WAL-режимом и автоматическим созданием схемы;
- подписанная HttpOnly-сессия, ограничение частоты запросов и security-заголовки;
- Open Graph-изображение, favicon, sitemap и robots.txt.

## Структура

```text
public/                 публичный сайт и админка
src/server.js           HTTP-сервер и API
src/database.js         SQLite-схема и запросы
src/validation.js       проверка входных данных
data/vyraz.sqlite       база, создаётся при первом запуске
```

## Локальный запуск

Нужен Node.js `20.3` или новее.

```bash
npm ci
cp .env.example .env
npm run dev
```

В `.env` замените `ADMIN_PASSWORD` на длинный уникальный пароль. Сайт откроется на `http://localhost:3000`, админка — на `http://localhost:3000/admin`.

## Проверка и production

```bash
npm test
npm run check
npm start
```

Подробная инструкция для обычного Node-хостинга, панели управления и VPS находится в [`DEPLOY.md`](./DEPLOY.md).
