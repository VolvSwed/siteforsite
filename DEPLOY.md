# Как запустить VYRAZ.BY на хостинге

Проекту нужны серверные формы, админка и база, поэтому обычный GitHub Pages больше не подходит. Самый прямой вариант — Cloudflare Workers со Static Assets и D1.

## 1. Подготовьте Cloudflare

Создайте аккаунт Cloudflare и добавьте туда зарегистрированный домен. Затем в терминале внутри проекта выполните:

```bash
npm install
npx wrangler login
```

## 2. Создайте базу

```bash
npx wrangler d1 create vyraz-content --jurisdiction eu
```

Команда напечатает `database_id`. Скопируйте его в `wrangler.jsonc`, заменив:

```text
00000000-0000-0000-0000-000000000000
```

Примените схему:

```bash
npm run db:remote
```

## 3. Задайте пароль админки

Используйте длинный уникальный пароль — он сохранится как зашифрованный секрет Cloudflare и не попадёт в GitHub:

```bash
npx wrangler secret put ADMIN_PASSWORD
```

Вставьте пароль в появившийся запрос. Минимальная длина, которую принимает приложение, — 12 символов.

## 4. Опубликуйте

```bash
npm run deploy
```

После публикации сайт будет доступен на временном адресе `*.workers.dev`. Админка находится по адресу `/admin`.

## 5. Подключите домен `.by`

В Cloudflare откройте `Workers & Pages` → `vyraz-by` → `Settings` → `Domains & Routes` → `Add` → `Custom Domain`, укажите ваш домен и подтвердите подключение. Для `vyraz.by` сначала отдельно проверьте доступность и зарегистрируйте имя у аккредитованного регистратора.

## Локальный запуск

```bash
npm install
cp .dev.vars.example .dev.vars
```

Откройте `.dev.vars`, замените пример пароля, затем выполните:

```bash
npm run db:local
npm run dev
```

Wrangler покажет локальный адрес, обычно `http://localhost:8787`. Админка: `http://localhost:8787/admin`.

## Обновления

После изменений в коде повторно выполните `npm run deploy`. Новые миграции базы сначала применяйте командой `npm run db:remote`.

Важно: сделайте резервные выгрузки D1 перед крупными изменениями и добавьте на сайт финальные реквизиты/политику обработки персональных данных перед приёмом реальных заявок.
