# VYRAZ.BY — сайты, боты и Mini Apps

Полноценный сайт digital-студии для белорусской аудитории. VYRAZ — это про ясное выражение идеи в дизайне и коде: коротко, запоминаемо и естественно выглядит с доменной зоной `.by`.

## Возможности

- адаптивный лендинг без горизонтальной прокрутки на мобильных;
- пять коротких слоганов, которые меняются при новом посещении;
- формы заявки и отзыва прямо на сайте;
- обязательные имя и email для отзыва, email никогда не отдаётся в публичный API;
- модерация отзывов перед публикацией;
- добавление, редактирование и удаление выполненных работ;
- управление заявками и текстами главного экрана;
- защищённая админка по адресу `/admin`;
- D1-база и серверная часть на Cloudflare Workers;
- Open Graph-изображение, favicon, sitemap и базовые security-заголовки.

## Структура

```text
public/                 сайт и админка
src/worker.js           API, авторизация и раздача статики
migrations/             схема D1-базы
wrangler.jsonc          конфигурация Cloudflare Worker
```

## Локальный запуск

Требуется Node.js `20.3` или новее.

```bash
npm install
cp .dev.vars.example .dev.vars
npm run db:local
npm run dev
```

Затем откройте адрес, который покажет Wrangler (обычно `http://localhost:8787`). В `.dev.vars` замените пример на длинный пароль администратора.

## Проверка

```bash
npm test
npm run check
```

Пошаговая публикация на Cloudflare и подключение домена описаны в [`DEPLOY.md`](./DEPLOY.md).
