# Как опубликовать KIN.DOT

Сайт статический: ему не нужны база данных, серверный язык или сборка. Для публикации достаточно загрузить содержимое репозитория на любой статический хостинг.

## Вариант 1 — GitHub Pages

1. Откройте репозиторий `VolvSwed/siteforsite` на GitHub.
2. Перейдите в `Settings` → `Pages`.
3. В блоке `Build and deployment` выберите `Source` → `Deploy from a branch`.
4. Выберите ветку `main`, папку `/ (root)` и нажмите `Save`.
5. Дождитесь завершения публикации.

Адрес сайта:

```text
https://volvswed.github.io/siteforsite/
```

После каждого нового изменения в ветке `main` GitHub Pages будет обновлять сайт автоматически.

## Вариант 2 — обычный хостинг

1. Скачайте репозиторий через `Code` → `Download ZIP`.
2. Распакуйте архив.
3. Загрузите в корневую папку сайта файлы `index.html`, `styles.css`, `script.js`, `.nojekyll`, `robots.txt` и папку `assets`.
4. Убедитесь, что `index.html` лежит именно в корне публичной директории — обычно это `public_html`, `www` или `htdocs`.
5. Подключите домен и HTTPS в панели хостинга.

## Свой домен на GitHub Pages

В `Settings` → `Pages` укажите домен в поле `Custom domain`, сохраните его и настройте DNS по подсказкам GitHub. Не отключайте `Enforce HTTPS` после выпуска сертификата.

## Локальная проверка перед публикацией

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.
