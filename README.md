# KIN.DOT — сайты, боты и Mini Apps

Рекламный одностраничный сайт digital product studio KIN.DOT. Название раскрывает позиционирование: «точка, где идея становится продуктом». Проект выполнен на чистых HTML, CSS и JavaScript — без сборщика, внешних библиотек и обязательных зависимостей.

## Что внутри

- адаптивный лендинг с авторской тёмной визуальной системой;
- пять hero-слоганов: при каждом посещении выбирается новый и появляется слово за словом;
- анимации появления, бегущая строка и интерактивная hero-композиция;
- услуги: сайты, Telegram-боты и Telegram Mini Apps;
- блоки с форматами запуска, процессом и ответами на вопросы;
- форма, которая собирает сообщение, копирует его и открывает чат `@kindow`;
- Open Graph-метаданные, favicon и базовый `robots.txt`;
- защита от горизонтальной прокрутки на мобильных устройствах;
- поддержка `prefers-reduced-motion` и управление мобильным меню с клавиатуры.

## Локальный запуск

Можно открыть `index.html` напрямую или запустить любой статический сервер, например:

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## Публикация на хостинге

Проект подходит для GitHub Pages, Netlify, Vercel и любого статического хостинга. Подробная пошаговая инструкция находится в [`DEPLOY.md`](./DEPLOY.md).
